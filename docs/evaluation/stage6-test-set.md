# Stage 6 自动测试照片集

本目录说明 V6.1 综合测试使用的照片来源与使用边界。

## 自动矩阵测试集

自动矩阵使用 `services/api/tests/test_stage6_matrix.py` 中生成的 128×96 合成图，
覆盖八类场景：

| 场景 | 合成特征 | 检查重点 |
| --- | --- | --- |
| 街头 | 方向性亮带 + 深色遮挡 | 光影、空间、人物关系 |
| 人像 | 肤色椭圆主体 + 柔和背景 | 肤色、曝光、背景 |
| 建筑 | 规则线条 + 高光立面 | 几何、明暗层次 |
| 自然风光 | 天空渐变 + 地面 + 高光点 | 色彩、层次、高光 |
| 夜景 | 深色底 + 暖/冷灯光点 | 暗部、灯光色彩 |
| 室内 | 暖色渐变 + 窗光 | 白平衡、混合光源 |
| 逆光 | 强亮背景 + 暗主体 | 高光保护、主体曝光 |
| 低光 | 暗部渐变 + 噪声 + 小光源 | 噪声、暗部、对比 |

这些图案由代码确定性生成，不使用任何受版权保护的摄影作品，可以安全入库和重复运行。
它们用于验证引擎稳定性、边界和模式差异，**不能替代真实照片的人工视觉评价**。

## 真实照片人工验收

人工评价需要使用拥有合法使用权、且不专门为某一种风格挑选的照片。建议至少：

- 八类场景各 1 张；
- 每张选择 3 个不同风格；
- 每种风格覆盖 Natural / Style / Creative；
- 每种模式至少 2 档强度；
- 记录输入图、风格版本、模式、强度、方案、渲染结果、耗时、错误与评价。

照片与评价结果放在用户自己的受控目录，不提交到仓库。
